# PWA Icons

To make your PWA look professional, you need to create icon files:

## Required Icons

- `icon-192.png` - 192x192 pixels
- `icon-512.png` - 512x512 pixels

## Quick Options

### Option 1: Online Generator (Easiest)
1. Visit [PWA Builder Image Generator](https://www.pwabuilder.com/imageGenerator)
2. Upload your logo (512x512 recommended)
3. Download the generated icons
4. Place them in this `/public` folder

### Option 2: Design Tool
Use Figma, Canva, or Photoshop:
- Create 192x192 and 512x512 PNG files
- Use your brand colors
- Keep it simple and bold
- Export as PNG

### Option 3: Simple Text Icon
For W&P AI branding:
- Dark background: `#0A0E1A`
- "W&P" text in neon lime: `#D4FF00`
- Bold sans-serif font
- Centered

## Temporary Workaround

For now, the app will use browser default icons. The PWA will still work, just without custom branding.

## After Adding Icons

1. Save `icon-192.png` and `icon-512.png` to `/public` folder
2. Clear browser cache
3. Reinstall PWA on mobile device
4. Icons should appear!
